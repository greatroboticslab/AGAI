\section{Introduction}

Automated plant disease diagnosis exhibits two distinct failure modes that
require separate treatment. The first is categorical misclassification, in
which a model assigns an incorrect disease label to an input image. The
second, which we refer to as \emph{report failure}, occurs when a generative
model produces a fluent, detailed explanation that is not in fact supported
by the image content. Recent work on multimodal hallucination has documented
this failure mode in vision-language systems across general
domains~\citep{huang2024hallucinationsurvey}. In agricultural decision
support, where the consumer of the output is a grower making management
decisions, the second failure mode is at least as costly as the first: a
confident but unfounded treatment recommendation can damage a crop more
reliably than an honest expression of uncertainty.

A single end-to-end vision-language model has structural difficulty
addressing both failure modes simultaneously. It must commit to a label,
produce a justification for that label, and quantify uncertainty, all from
the same generative head. AGAI takes a different approach: we factor the
problem into three stages, each with a single responsibility.

\begin{enumerate}[leftmargin=1.3em]
    \item A calibrated ResNet-50 classifier~\citep{he2016resnet,guo2017calibration}
    serves as the sole authority for the categorical diagnosis. The
    deployed pipeline gates this output by a per-class confidence
    threshold, demoting low-confidence predictions to an explicit
    \texttt{unknown} state.
    \item An RF-DETR Small object detector~\citep{robinson2025rfdetr,carion2020detr},
    fine-tuned for strawberry plant parts (\emph{flower}, \emph{fruit},
    \emph{leaf}, \emph{root}, \emph{soil}, \emph{stem}), produces a
    visibility constraint that restricts the language model to discussing
    only those parts that are present in the image.
    \item A LoRA-adapted MiniGPT-v2 report writer~\citep{chen2023minigptv2,hu2021lora,touvron2023llama2}
    receives the classifier label and the detector visibility constraint
    as inputs and is trained to explain rather than re-predict the
    diagnosis.
\end{enumerate}

This paper documents the system at its current measured state. We make four
contributions.

\paragraph{Contribution 1: Reproducible split protocol.}
We describe and justify a balanced 70-image holdout (10 images per class
across seven classes) maintained by physical relocation, an augmented
training root rebuilt from a compact source root and balanced to a minimum
class floor of 300 by deterministic photometric and geometric
augmentation~\citep{shorten2019augmentation}, and an external-image audit
that adds only conservatively labelled, non-duplicate examples.

\paragraph{Contribution 2: Calibrated classifier evaluation.}
We retrain a ResNet-50 classifier on the rebuilt augmented root, calibrate
it via post-hoc temperature scaling, and report top-1 and top-2 accuracy,
expected calibration error~\citep{naeini2015ece}, per-class confusion, and
Wilson 95\% confidence intervals~\citep{wilson1927interval} for per-class
accuracy on the balanced holdout.

\paragraph{Contribution 3: Detector-grounded runtime stack.}
We formalize the deployed pipeline, including the per-class acceptance
gate, the visible-/not-visible-part prompt assembly, optional retrieval
from a curated disease knowledge graph, and a heuristic phrase-level
hallucination-retry mechanism. Detection performance for the RF-DETR
backbone is reported on the held-out validation split using standard COCO
metrics~\citep{lin2014cocoeval}.

\paragraph{Contribution 4: Constrained dual-report supervision.}
We describe an offline data-generation policy that produces a primary
farmer-facing report for every image and conditionally produces a second,
ambiguity-aware report only when the classifier's top-2 distribution and a
pre-specified pair whitelist jointly indicate a semantically plausible
alternative. We report results from a controlled 20-image pilot under this
policy.

We also identify the experiments that remain open. Full stage-2 regeneration
under the constrained policy, MiniGPT-v2 retraining on the regenerated
targets, and clean holdout explanation evaluation with and without the
RF-DETR grounding constraint are pending. We retain those steps as future
work and limit our claims to results obtained from the current artifacts.
