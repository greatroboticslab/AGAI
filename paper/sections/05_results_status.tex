\section{Current Experimental Results}

The current results divide naturally into two layers. The classifier layer is fully measured on a clean seven-class holdout. The report-generation layer has completed a tightened pilot for stage-2 target construction, but its full regenerated training set, retrained checkpoint, and clean holdout explanation metrics are still in progress. The sections below therefore emphasize completed classifier results first and then treat the dual-report pilot as a dataset-generation result rather than a finished end-to-end benchmark.

\subsection{Runtime Gating Behavior and Top-2 Structure}

The classifier accuracy story is not the whole runtime story. A report can still be blocked if the threshold gate demotes a correct label to \texttt{unknown}. That gate remains threshold-only in the live runtime, with p1/p2 margins recorded for later analysis but not yet activated as a runtime demotion rule. The current paper therefore treats the holdout metrics as classifier metrics first, not as final deployed diagnosis rates.

The top-2 structure remains informative because the ambiguity pilot is built around close alternatives rather than free-form speculation. The report-generation policy still only allows ambiguity for semantically realistic disease pairs under a strict margin rule, and the current pilot should be read as a controlled dataset-generation experiment rather than a user-facing ambiguity feature.

\subsection{Tight Dual-Report Pilot}

The current dual-report pilot is not a full dataset regeneration. It is a focused evaluation of whether the stage-2 policy produces useful training targets rather than boilerplate or semantically absurd alternatives.

The important qualitative outcome is that the tightened policy eliminates bizarre alternatives that arise from raw numeric proximity alone. Under the current strict margin rule and pair whitelist, the surviving ambiguity cases in the focused pilot are disease pairs that are visually and operationally plausible, rather than arbitrary second-ranked classes.

This pilot therefore supports three limited claims:
\begin{enumerate}[leftmargin=1.3em]
\item The dual-report plumbing works end to end.
\item The strict ambiguity policy can suppress obviously implausible alternatives.
\item The current pilot outputs are good enough to motivate full stage-2 regeneration.
\end{enumerate}

It does \emph{not} support a clean claim about final explanation quality on the post-carve holdout, because the current deployed MiniGPT checkpoint predates the full regeneration and retrain that would be required for that claim.

\subsection{What Is Still Not Measured}

Several experiments remain deliberately unreported because they are not yet clean.

First, the current stage-2 training annotations do not yet encode the tightened dual-report policy at full scale. Second, the current MiniGPT checkpoint predates the balanced split and the current stage-2 redesign. Third, no clean holdout explanation rubric has yet been applied to a retrained post-regeneration checkpoint. Fourth, the RF-DETR on/off ablation is planned but not yet executed on that clean holdout. Those missing steps are not minor bookkeeping. They are the difference between a promising report-generation pilot and a finished end-to-end explanation result.
