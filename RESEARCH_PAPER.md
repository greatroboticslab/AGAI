## Abstract

AGAI is a strawberry disease diagnosis pipeline that combines a calibrated ResNet classifier, RF-DETR part grounding, and MiniGPT-based report generation. The current manuscript documents the balanced seven-class holdout protocol, ResNet v3 evaluation on a 140-image holdout with 20 samples per class, the grounded runtime pipeline, and the dual-report data generation strategy used for structured diagnostic report supervision. The paper reflects the current repository state rather than the earlier proposal-stage manuscript.
