\section{Discussion}

The current system supports a stronger classifier claim than language-model claim, and the paper should say so plainly.

On the classifier side, the methodology is now substantially cleaner than it was during the earlier development phase. The active holdout is physically separate, the current split support is balanced across classes, the augmented training split has been raised to a minimum floor for the previously underrepresented classes, and the current checkpoint is evaluated on that active dataset state. That is enough to support the classifier results in this manuscript with confidence.

On the language side, the story is more nuanced. The runtime integration of MiniGPT, RF-DETR, and RAG is real. The prompt-design work is real. The dual-report pilot is real. But the current MiniGPT checkpoint still predates the fully regenerated balanced stage-2 dataset, which means any strong claim about holdout explanation quality would still be contaminated by outdated supervision. The correct interpretation is therefore that the report-generation redesign is promising but not yet complete enough for a final benchmark claim.

The current threshold policy still deserves separate treatment from raw classifier accuracy. The classifier can be correct while the deployment gate suppresses a diagnosis, and the converse can also happen on harder cases. This is a reminder that classifier quality and deployed diagnosis rate are not identical. The current paper does not retune those thresholds because the project now has p1/p2 runtime logging and should use real decision data rather than intuition for future retuning.

The ambiguity work is valuable for the same reason. A naive ``top-2 means possible alternative'' rule is not safe. Raw ResNet probabilities can surface numerically close but semantically implausible competitors. The pilot only became credible after the policy was tightened with both a lower margin threshold and a realistic pair whitelist. That is exactly the sort of upstream-downstream interaction that matters in a system paper: the usefulness of ambiguity is not determined by the language model alone. It depends on how the classifier's uncertainty structure is filtered before it ever becomes text.

Finally, this project should be judged against the right target. The goal is not to maximize fluent prose. The goal is to produce a usable agricultural diagnostic system in which the diagnosis is anchored, the report is grounded, and uncertainty is surfaced honestly. Under that definition, the current paper is strongest when it reports the measured classifier and pilot results cleanly, while reserving full end-to-end language claims for the retrained model and the clean holdout evaluation that still need to be completed.
