# `v1/plant_diagnostic/xtra/`: photo-source lists and a letter to farms

Office files from v1's photo collection, first committed on 29 September 2025 (v1, 2025 to April 2026): lists of web
pages about strawberry frost injury, drought and root rot, and a draft letter. No code reads them.

## Contents

| File | Contents |
|---|---|
| [`For the farmers.._.docx`](For%20the%20farmers.._.docx) | one-page draft letter from the lab to farms, asking for donated photographs of strawberries affected by drought |
| [`Frost Conditions, strawberries.xlsx`](Frost%20Conditions,%20strawberries.xlsx) | 100 rows, each a linked title of a web page about frost damage to strawberries |
| [`Unhealthy.xlsx`](Unhealthy.xlsx) | 20 links, most of them to news and photo pages about drought in strawberry fields, and one embedded GIF image; 14 MB, stored as a regular git file |
| [`rootrot_Root Rot Sources.xlsx`](rootrot_Root%20Rot%20Sources.xlsx) | 150 linked rows (148 shown as web addresses) about strawberry root diseases (black root rot, red stele and others), from extension services, research articles and blogs |
