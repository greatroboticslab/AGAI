\begin{abstract}
This paper reports the current state of AGAI, a strawberry disease diagnosis pipeline that couples a ResNet-50 classifier, RF-DETR part grounding, and a report-generation stage built on MiniGPT-v2. The current dataset has been rebalanced in two ways. First, the active holdout now contains 20 images for each of the seven classes, giving a balanced 140-image evaluation split. Second, the augmented training split has been topped up to a minimum of 300 images for every underrepresented class using lightweight deterministic image augmentation. On this balanced holdout, the current ResNet v3 checkpoint reaches 83.57\% top-1 accuracy, 92.14\% top-2 accuracy, and 6.15\% expected calibration error under two-view test-time augmentation and temperature scaling. Gray mold and root rot each reach 100.0\% top-1 accuracy, healthy reaches 95.0\%, frost and white mold each reach 85.0\%, overwatered reaches 70.0\%, and drought reaches 50.0\%.

The runtime stack includes a threshold-based acceptance gate, RF-DETR part grounding, optional knowledge-graph retrieval, and heuristic hallucination-retry logic. On the language side, the system now has a tightened offline dual-report generation path that uses GPT-5.4 only during dataset construction. The current pilot generates one standard farmer-facing report for every image and conditionally generates a second ambiguity-aware report only for semantically realistic close pairs under a strict margin policy. The focused pilot completed successfully with 36 generated records from 20 images, including 2 tightly gated ambiguity reports and no fallback generations.

The resulting manuscript is a current technical paper for the project as it exists now. The classifier side is measured on the active balanced split. The report-generation side has a completed pilot and a clear next step for full stage-2 regeneration, retraining, and clean holdout explanation evaluation.
\end{abstract}
