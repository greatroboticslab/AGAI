\section{Related Work}

Image-based plant disease classification has been studied extensively, especially since the availability of curated crop image datasets and transfer learning from ImageNet-scale backbones. Mohanty et al. showed that deep convolutional networks can perform strongly on plant disease datasets when given labeled images and sufficient transfer-learning support \citep{mohanty2016plantdisease}. That result helped establish the basic feasibility of smartphone-style plant diagnosis, but most work in that tradition terminates at classification. It does not address how a system should explain its answer, how it should qualify uncertainty, or how it should avoid detailed but unsupported claims.

ResNet remains a strong baseline for this setting because its residual formulation supports deep feature extraction without the optimization instability that affected earlier very deep CNNs \citep{he2016resnet}. In AGAI, the important point is not that ResNet is novel. The important point is that a calibrated ResNet-50 can serve as a high-precision disease anchor while the language model is constrained to explain rather than relabel.

Calibration matters because a diagnostic system should use probabilities in a meaningful way, not merely output them. Guo et al. showed that modern neural networks are often miscalibrated and that temperature scaling provides a simple and effective post-hoc correction \citep{guo2017calibration}. AGAI follows that practical recipe. Two-view test-time augmentation and temperature scaling are used to produce the classifier probabilities that drive both the runtime acceptance gate and the offline ambiguity pilot.

On the language side, the current system inherits its report-writing backbone from the MiniGPT line of models \citep{zhu2023minigpt4, chen2023minigptv2}, which align a vision encoder with a large language model. The active repository configuration uses Llama 2 as the language backbone \citep{touvron2023llama2} and LoRA for parameter-efficient adaptation \citep{hu2021lora}. These choices are pragmatic rather than novel. The distinctive feature in AGAI is the surrounding policy: the language model is not treated as a free diagnostician. It is trained and prompted as a constrained report generator.

That distinction connects AGAI to broader work on guardrails and grounded generation. In mission-critical domains such as medicine, safety, and defense, a model that expresses uncertainty honestly can be more useful than a model that simply maximizes fluency. The ambiguity work reported here should be read in that tradition. The goal is not to let the language model wander through the seven disease classes. The goal is to teach it a narrow and useful uncertainty behavior when the classifier itself exposes a plausible close alternative.

AGAI still differs from many guardrail settings in one important respect. The live product must remain fully local and free at inference time. GPT-5.4 is used only offline during stage-2 dataset generation. That means any improvement has to survive deployment without access to GPT or external scoring signals. The system must therefore learn better behavior from better targets, not from a runtime API dependency.
